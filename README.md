## ✨ About

This repository is my personal archive of **computer-aided design** work. It collects drawings and models built while learning and practicing with **AutoCAD**, **CATIA**, and **Autodesk Fusion**, showing how the same design thinking translates across different tools.

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/faraninm/My-CAD-Projects.git
cd My-CAD-Projects
```

**2. Open the folder for your software**, then launch any file in the matching application.

> 💡 **No CAD software?** Try the free [Autodesk Viewer](https://viewer.autodesk.com/) to open many DWG and Fusion files right in your browser.
